# ppt2html

一个将 PowerPoint (`.pptx`) 文件转换为 HTML 的实用脚本，同时尽可能保留原始演示文稿中的结构、布局和元数据。

## 功能特性

* 导出每一页幻灯片为独立的 HTML `section`，并保留标题、布局等元信息。
* 还原文本、图片、表格、分组、图表等常见对象的位置、大小、旋转等属性。
* 提取幻灯片中的图片、背景等资源到独立的资产目录。
* 将图表数据转为表格并嵌入，同时以 JSON 形式保存完整的图表元数据。
* 为每个图形对象写入 JSON 元数据，包含颜色、边框、文本内容等，方便后续处理或二次开发。

## 使用方式

1. 安装依赖：

   ```bash
   pip install python-pptx
   ```

2. 运行转换脚本：

   ```bash
   python ppt2html.py input.pptx -o output.html
   ```

   如果不指定 `-o/--output` 参数，脚本会在与源文件相同的目录下生成同名的 `.html` 文件，以及对应的 `_assets` 资源目录。

3. 打开生成的 HTML，即可在浏览器中查看保留了布局和内容信息的幻灯片。

> 提示：生成的 HTML 会在每个幻灯片和图形对象内部嵌入 `application/json` 的元数据脚本，便于调试或做进一步的数据提取。
